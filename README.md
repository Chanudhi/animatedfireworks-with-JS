# New Year Fireworks 🎉

A festive interactive web application featuring animated fireworks and character selection. This application combines holiday cheer with engaging visual effects to create a delightful user experience.

## Features

- 🎆 Interactive fireworks animation
- 🎅 Character selection feature
- 🎨 Dynamic canvas background
- 📱 Responsive design
- 🎮 Click interaction for fireworks display

## Technologies Used

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
- No external dependencies required

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Basic local development server (optional)

### Installation

1. Clone this repository:
   ```bash
   git clone [https://github.com/Chanudhi/animatedfireworks-with-JS]
   ```

2. Navigate to the project directory:
   ```bash
   cd new-year-fireworks
   ```

3. Open `index.html` in your web browser or serve it through a local development server.

## Usage

1. Open the application in your web browser
2. Click anywhere on the screen to create fireworks
3. Click on the avatar to switch between different characters
4. Enjoy the festive animations and background effects!

## Project Structure

```
├── index.html              # Main HTML file
├── styles.css             # CSS styles
├── avatar-toggle.js       # Character selection logic
├── canvas-background.js   # Background animation
├── canvas-fireworks.js    # Fireworks animation
└── assets/               # Image assets
```
